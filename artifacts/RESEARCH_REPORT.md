## 1. Problem Statement & Market Landscape
CLI and web tool to transform Markdown, HTML, JSON, and LaTeX with syntax highlighting and asset bundling.
Existing tools in this domain suffer from high operational bloat, cloud subscription fees, and complex setup requirements.
DocuMorph-CLI fills this gap as a lightweight, zero-dependency, self-hosted solution.

## 2. Technology Stack
Node.js, AST Parsing, Document Engine, Docker
